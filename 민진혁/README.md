# AI 회의록 & 과제 도우미 - 과제 관리 모듈 (Part 4)

본 모듈은 'AI 회의록 & 팀 과제 정리 도우미' 프로젝트의 **과제 관리 시스템**을 담당합니다. 팀 프로젝트의 효율적인 할 일 관리를 위한 시각적 칸반 보드와 실시간 데이터 동기화 기능을 제공합니다.

---

## 🚀 상세 기능 설명

### 1. 시각적 칸반 보드 (Kanban Board)
- **상태 관리**: 과제는 [미시작(Not Started)], [진행 중(In Progress)], [완료(Done)] 3가지 상태로 구분됩니다. 각 상태는 독립적인 컬럼에 표시되어 업무 흐름을 한눈에 파악할 수 있습니다.
- **드래그 앤 드롭(Drag & Drop)**: 
  - 카드를 마우스로 끌어 다른 컬럼에 놓으면 상태가 즉시 변경됩니다.
  - 컬럼 내에서 카드를 위아래로 끌어 놓으면 원하는 순서로 재배치가 가능하며, 이 순서는 `Order` 속성으로 관리되어 영구 저장됩니다.
- **자동/수동 정렬**:
  - **정렬 ON**: 과제의 마감일(DueDate)을 기준으로 자동으로 오름차순 정렬됩니다.
  - **정렬 OFF**: 사용자가 직접 드래그로 배치한 순서(`Order`)를 유지합니다.

### 2. 강력한 데이터 관리 (Data Persistence)
- **실시간 JSON 저장**: 모든 상태 변경(이동, 추가, 수정, 삭제)은 별도의 저장 버튼 없이 `DataManager`를 통해 `project_data.json`에 실시간으로 반영됩니다. 프로그램 재실행 시에도 데이터가 유지됩니다.
- **CRUD 상세**:
  - **생성 (Create)**: 상단 '+ 새 과제 추가' 버튼을 통해 담당자, 내용, 마감일, 우선순위를 설정하여 생성합니다.
  - **읽기 (Read)**: `Form1` 로드 시 JSON에서 데이터를 파싱하여 화면에 동적으로 생성합니다.
  - **수정 (Update)**: 과제 카드 더블 클릭 시 `AddTaskForm`이 수정 모드로 열려 기존 정보를 안전하게 수정할 수 있습니다.
  - **삭제 (Delete)**: 카드 우측 상단의 'X' 버튼 클릭 시 확인 창을 거쳐 영구 삭제합니다.

### 3. 고도화된 업무 지원 (Advanced Features)
- **실시간 검색**: 검색창에 담당자명 또는 과제 내용을 입력하면 키워드가 포함된 카드만 즉시 필터링하여 보여줍니다.
- **우선순위 시스템**:
  - 과제마다 [긴급, 보통, 낮음] 우선순위를 부여할 수 있습니다.
  - 카드 좌측에 시각적 색상 띠(긴급: 빨강, 보통: 노랑, 낮음: 초록)를 표시하여 중요도를 즉시 인지할 수 있습니다.
- **진행률 대시보드**: 전체 과제 수 대비 완료된 과제 수를 계산하여 상단 프로그레스 바(ProgressBar)에 백분율(%)로 표시합니다.
- **시각적 알림**: 마감일이 오늘 날짜와 일치하는 과제는 글자 색상을 빨간색으로 변경하고 굵게 표시하여 마감 임박을 알립니다.

## 💡 통합 가이드 (조원용)
다른 모듈과 통합 시 다음 사항을 참고하세요.

1.  **데이터 공유**: 모든 모듈은 `Models` 폴더의 `ProjectData.cs` 모델을 공유하며 `Services/DataManager.cs`를 통해 데이터를 읽고 씁니다.
2.  **데이터 구조**: `DataManager.SaveData(ProjectData data)`와 `DataManager.LoadData()`를 사용하여 프로젝트 전체 데이터를 동기화합니다.
3.  **UI 구성**: 메인 대시보드(`Form1`)에 각 조원들의 기능을 `UserControl` 형태로 탑재하여 통합하는 방식을 권장합니다.
4.  **의존성**: 프로젝트의 모든 데이터 흐름은 단일 JSON 파일 동기화를 원칙으로 합니다.
