# AI 회의록 & 과제 도우미 UI 레이아웃 가이드

본 문서는 현재 구현된 WinForms 애플리케이션의 시각적 구조를 설명합니다. 비주얼 스튜디오의 디자이너 뷰를 대신하여 전체적인 배치를 파악하는 데 사용하세요.

---

## 1. 메인 화면 (Form1) 전체 구조
메인 화면은 **3개 열의 칸반 보드** 형식입니다.

```text
+-----------------------------------------------------------------------+
|                         AI 회의록 & 과제 도우미                       |
+-----------------------------------------------------------------------+
|       To-Do / 미시작       |    In Progress / 진행 중    |      Done / 완료      |
+----------------------------+----------------------------+---------------------+
| [Task Card 1]              | [Task Card 2]              | [Task Card 4]       |
| - 내용: UI 구현            | - 내용: DB 설계            | - 내용: 문서화      |
| - 담당자: 이영희           | - 담당자: 김철수           | - 담당자: 최지우    |
| [시작하기 ->]              | [완료하기 ->]              |                     |
|                            |                            |                     |
| [Task Card 3]              |                            |                     |
| - 내용: 알고리즘 검토      |                            |                     |
| [시작하기 ->]              |                            |                     |
|                            |                            |                     |
| (여백/스크롤 가능)          | (여백/스크롤 가능)          | (여백/스크롤 가능)  |
+----------------------------+----------------------------+---------------------+
```

### 주요 설정
- **전체 크기**: 900 x 600 (실행 시 조절 가능)
- **레이아웃**: `TableLayoutPanel`을 사용하여 3개의 열이 항상 1:1:1 비율(33.3%)을 유지합니다.
- **배경색**:
    - To-Do: 연한 회색 (F0F0F0)
    - In Progress: 연한 파란색 (E6F0FF)
    - Done: 연한 초록색 (E6FFE6)

---

## 2. 과제 카드 컴포넌트 (TaskCard UserControl)
각각의 과제는 아래와 같은 독립적인 카드 형태로 표시됩니다.

```text
+----------------------------+
|  과제 내용 (굵은 글씨)      |
|                            |
|  담당자: 홍길동            |
|  마감일: 2026-06-07  [버튼] |
+----------------------------+
```

### 주요 기능
- **마감일 하이라이트**: 오늘 날짜와 마감일이 일치하면 글자가 **빨간색**으로 변합니다.
- **상태 전환 버튼**: 
    - `Not Started` 상태: **[시작하기 ->]** 버튼 표시
    - `In Progress` 상태: **[완료하기 ->]** 버튼 표시
    - `Done` 상태: 버튼이 사라집니다.

---

## 3. 비주얼 스튜디오에서 디자인 보는 법
코드 대신 마우스로 디자인을 보고 싶으시다면 비주얼 스튜디오에서 다음을 수행하세요:

1. **솔루션 탐색기**에서 `Form1.cs` 파일을 찾습니다.
2. 파일을 마우스 오른쪽 버튼으로 클릭합니다.
3. **[디자이너 보기 (View Designer)]** 또는 `Shift + F7`을 누릅니다.
4. `Controls/TaskCard.cs` 파일도 동일한 방법으로 개별 카드 디자인을 볼 수 있습니다.
