# AI Meeting Assistant Dashboard

AI Meeting Assistant Dashboard는 회의록을 분석하여 퀴즈를 생성하고 작업 항목을 추출하는 C# WinForms 기반의 생산성 도구입니다.

## 주요 기능

### 1. 칸반 보드 (Task Management)
- **카드 기반 작업 관리**: 작업을 카드 형태로 시각화하여 To-Do, In Progress, Done 상태로 관리합니다.
- **드래그 앤 드롭**: 카드를 드래그하여 상태를 변경하거나 순서를 자유롭게 재정렬할 수 있습니다.
- **상태 변경**: 각 카드의 진행 버튼을 통해 작업 상태를 단계별로 업데이트할 수 있습니다.
- **정렬 및 검색**: 마감일 기준으로 작업을 정렬하거나, 내용/담당자별로 작업을 빠르게 검색할 수 있습니다.
- **작업 삭제**: 각 카드의 'X' 버튼을 통해 불필요한 작업을 삭제합니다.

### 2. AI 회의 도우미 (AI Insights)
- **AI 퀴즈 생성**: 회의 내용을 기반으로 퀴즈를 생성하여 주요 내용을 복습할 수 있습니다.
- **태스크 자동 추출**: 회의록 분석을 통해 수행해야 할 작업 항목을 자동으로 추출하여 칸반 보드에 추가합니다.
- **Groq API 통합**: Microsoft Semantic Kernel을 통해 Groq API(`openai/gpt-oss-20b`)와 연동되어 지능형 분석을 수행합니다.

### 3. 회의 히스토리 관리
- **회의 기록 저장**: AI 분석(퀴즈 생성)을 수행할 때마다 회의 내용과 생성된 퀴즈가 자동으로 기록됩니다.
- **히스토리 조회**: 과거 회의 내역을 목록으로 확인하고, 특정 회의를 선택하여 당시의 회의 요약과 퀴즈 내용을 다시 조회할 수 있습니다.

### 4. 데이터 관리
- **로컬 JSON 데이터 저장**: 모든 작업 데이터, 회의 히스토리, 퀴즈 이력은 `project_data.json` 파일에 로컬로 저장되어 재실행 시에도 데이터가 유지됩니다.

## 기술 스택
- **언어/프레임워크**: C# .NET 10.0 (Windows Forms)
- **AI 통합**: Microsoft Semantic Kernel (Groq API 연결)
- **데이터 저장**: System.Text.Json (JSON 직렬화)

## 사용 방법
1. 프로젝트를 빌드하고 실행합니다.
2. 메인 대시보드에서 '+ 새 과제 추가'를 통해 작업을 직접 생성하거나, AI 도우미 기능을 활용해 회의록을 분석합니다.
3. 드래그 앤 드롭을 사용하여 칸반 보드 내에서 작업 상태를 관리합니다.
4. 필요 시 정렬 기능을 켜고 끄며 마감일 순으로 작업을 확인합니다.
